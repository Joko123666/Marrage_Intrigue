# UI 와이어프레임

이 문서는 현재 구현된 단일 씬 UI의 화면 배치와 전환 규칙을 기록한다. 새 UI 요소를 추가하거나 화면 전환을 바꾸면 이 문서를 같이 갱신한다.

> 2026-07-29에 추가한 고전 육성 시뮬레이션 참고 리디자인은 [프린세스 메이커 계열 참고 UI 방향](ui_concepts/PRINCESS_MAKER_INSPIRED_UI_DIRECTION.md)에서 와이어프레임, 비주얼 목업, 색상 토큰과 함께 확인한다. 현재 구현 규칙과 목표 디자인이 충돌하면 해당 문서의 구현 순서를 따라 단계적으로 전환한다.

## 전체 레이아웃

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 배경 이미지: 귀족 저택 복도 + 어두운 오버레이                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ 헤더: 게임명 | 나이/주차 | 자금 | 피로 | 신분 | 의심 | 출신소문              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 내비게이션                                                                  │
│ [대시보드] [자유행동] [상점] [인물] [페르소나] [소문] [후보] ... [새 게임]  │
├───────────────────────────────────────────────┬─────────────────────────────┤
│ 메인 콘텐츠 스크롤 영역                        │ 행동 로그                   │
│ - 현재 화면 제목                               │ - 최근 상태 변화            │
│ - 화면별 카드/버튼/레이더/목록                 │ - 판정 결과                 │
│ - 반투명 패널 기반 카드                        │ - 튜토리얼 진행 흔적        │
└───────────────────────────────────────────────┴─────────────────────────────┘
```

## 공통 UI 규칙

- 모든 화면은 `Main.gd`에서 `current_screen` 값으로 전환한다.
- 맞선 안에서 턴을 갱신하는 경우를 제외한 일반 화면 전환은 본문 스크롤을 항상 상단으로 초기화한다.
- 기준 해상도는 1280x720이며 창 크기 변화 시 Control UI가 확장되도록 스케일 정책을 둔다.
- 화면 폭이 좁으면 본문/로그 영역은 세로 배치로 전환하고 헤더는 두 줄 요약으로 표시한다.
- 980px 미만의 일반 화면에서는 행동 로그를 기본으로 접고 `펼치기/접기` 버튼으로 필요한 경우에만 높이를 사용한다.
- 공통 헤더와 내비게이션은 항상 보인다.
- 조건부 화면 버튼:
  - `맞선`: 진행 중인 맞선이 있을 때 표시.
  - `결혼식`: 맞선 성공 후 결혼 대기 상태일 때 표시.
  - `배우자`, `처리`: 결혼 중일 때 표시.
  - `은폐`: 사건 파일이 있을 때 표시.
- 현재 화면에 해당하는 내비게이션 버튼은 금색/갈색 톤으로 강조한다.
- 진행 중 `새 게임`을 선택하거나 기존 빠른 저장·수동 슬롯을 덮어쓸 때는 전용 확인 패널로 결과와 복구 가능성을 안내한 뒤 실행한다. 게임오버 화면의 새 게임은 즉시 시작할 수 있다.
- 카드 UI는 반투명 어두운 패널과 금색 계열 테두리를 사용한다.
- 버튼은 짙은 갈색/버건디 계열이며 비활성 상태는 흐리게 보인다.
- 긴 설명은 자동 줄바꿈한다.
- 플레이어에게 보이는 텍스트에는 내부 id를 그대로 노출하지 않는다.
- 정수 수치는 `42.0`이 아니라 `42`처럼 표시한다.
- 스탯/위험 수치는 라벨-값 쌍을 한 줄 그리드로 나누지 않고 작은 카드로 표시한다.
- 주인공, NPC, 후보, 배우자 카드는 좌측 초상화와 우측 정보/버튼의 가로 배치를 기본으로 한다.
- 작은 창에서는 초상화와 정보 영역을 세로로 쌓고, 스탯/위험 카드는 2열로 줄인다.
- 필터, 상점, 저장 버튼 묶음은 작은 창에서 줄바꿈 가능한 버튼 행으로 표시한다.
- 전체 화면에는 낮은 투명도의 낡은 양피지/가죽 질감 오버레이를 깐다.
- 화면 제목 아래에는 금속 세공 구분선 장식을 배치한다.
- 공통 카드 상단에는 얇은 중세 플라크 장식을 넣되, 본문 텍스트와 버튼 영역은 침범하지 않는다.

## 대시보드

```text
┌ 혼인 모략/신분 ─ 날짜·나이 ─ 자금 ─ 체력 ┐
├──────────────┬───────────────────┬─────────┤
│ 생활 공간 속 │ 이번 달의 목표    │ 능력    │
│ 주인공       │ 진행률/바로가기   │ 평판    │
│ 대사 단계    ├───────────────────┤ 위험    │
│ 페르소나     │ 주간 일정 3칸     │ 장부 탭 │
│ 현재 목표문  │ 행동 추가/일정 취소│ 막대/값 │
│              │ [일정 확정·실행]  │         │
│              │ 조언              │         │
├──────────────┴───────────────────┴─────────┤
│ [자유행동] [인물] [소문] [후보] [상점] [페르소나] │
├────────────────────────────────────────────┤
│ 상세 전략 현황 / 성장 여정 / 전체 수치 / 저장 │
└─────────────────────────────────────────────┘
```

목적:

- 현재 루프의 다음 행동을 안내한다.
- 생활 공간과 주인공을 가장 큰 감정적 초점으로 둔다.
- 현재 목표, 다음 세 행동, 능력/평판/위험을 첫 화면 높이에서 비교한다.
- 일정에는 상점 진입처럼 즉시 별도 화면이 필요한 행동을 제외한 장기 행동을 최대 3개 예약한다.
- 일정 확정 시 위에서 아래 순서로 행동을 실행하고, 자원 조건을 만족하지 못하는 시점에 남은 일정을 중단한다.
- 예약한 일정 아래에는 현재 능력·컨디션 기준 총 주차와 누적 예상 효과를 표시한다. 실행 중단 시 실행하지 못한 일정은 삭제하지 않고 예약 칸에 남긴다.
- 예약 상태는 저장 데이터에 포함하지 않는 미확정 계획이며 새 게임에서는 초기화한다.
- 현재 목표에 맞는 화면으로 바로 이동하며, 작은 창에서는 2열, 모바일에서는 1열로 재배치한다.
- 기사 튜토리얼 수직 절편의 단계별 완료/진행/대기 상태를 표시한다.
- 수치 상태를 한눈에 확인한다.
- 수치를 현재 상태 요약, 경보, 추천 행동으로 해석해 보여준다.
- 주인공 이미지와 배경으로 게임 분위기를 고정한다.

## 자유행동

```text
┌ 행동 카드 ────────────────────────────────┐
│ 카테고리 문양 / 행동명 / 소요 주 / 장면   │
│ 요약                                      │
│ 실제 예상 효과 / 현재 수행감 / 능력 영향  │
│ [훈련 시작/일하러 가기/휴식] 또는 [불가]  │
└───────────────────────────────────────────┘

행동 완료 결과 장면:

```text
┌ ◆ 육성 기록 ◆ ───────────────────────────┐
│ 행동명                                    │
│ 행동별 생활 서술                          │
│ [실제 상승] [실제 하락/피로]              │
│ 경과 주차 · 장부 기록 안내                │
│ 배경: 거울방 / 서재 / 시장 골목            │
└───────────────────────────────────────────┘
```
```

특수 규칙:

- 상단 필터로 전체/자금/성장/소문/사교/회복/상점 행동을 구분한다.
- `상품 구매`는 실행 후 상점 화면으로 이동한다.
- `소문 조사`는 기사 후보 발견/정보 품질 상승과 연결된다.
- 피로/스트레스 비용은 현재 수치가 아니라 실행 후 100 초과 여부로 제한한다.
- 행동 카드에는 능력 영향으로 계산된 현재 수행감과 최종 예상 효과를 표시한다.
- 실행 후 일반 완료 배너 대신 전용 생활 결과 장면을 출력한다. 행동별 `result_ko`, 실제 적용 효과, 경과 주차를 한 화면에 묶는다.
- 행동의 `result_backdrop`을 16:9 채움으로 표시하고 중앙 암막을 겹쳐 텍스트 대비를 유지한다. 배경은 패널 수명과 분리된 느린 축소·밝기 전환으로 정착하며 결과 큐의 재생 시간을 늘리지 않는다.
- `외모 관리/가면 연습/휴식`은 거울방, `교양 공부/예법 훈련/사교계 참석`은 서재, `상품 구매/잡일/소문 조사·유포`는 시장 골목을 공유한다.
- 여러 행동을 일정으로 연속 실행하거나 월이 바뀌면 시간 경과 장면과 행동 결과 장면을 큐로 순차 재생한다.
- 모든 `TimeManager.advance_weeks()` 호출은 달력 월이 바뀌지 않아도 범용 시간 경과 장면을 출력한다. 일상 행동, 인물 상호작용, 정보 수집, 일정 실행 등 호출 주체와 무관하게 `시작 주 → 도착 주`, 경과 주차, 태양 궤적과 주차 눈금을 같은 문법으로 표시한다.
- 같은 달의 짧은 경과는 `일상이 흐릅니다`, 월 전환은 `달이 바뀝니다`, 연도 전환은 `새로운 해가 밝습니다`로 단계화한다. 월·연도 전환만 날짜 범위를 양쪽에 표시하며 연도 전환은 나이와 금빛 표식을 추가한다.
- 시간 경과 장면은 특정 행동 배경 자산에 의존하지 않는 밤→새벽 추상 궤적을 사용한다. 모바일에서는 패널과 궤적 높이를 줄이고 `accessibility/reduce_motion` 설정에서는 궤적을 즉시 도착 상태로 표시한다.
- 시간 경과·행동 결과 장면이 표시되는 동안 아래 UI 입력을 차단한다. 행동 결과는 충분한 자동 표시 시간을 두고 클릭 또는 `Enter`로 다음 장면을 넘길 수 있다.

## 상점

```text
┌ 아이템 카드 ──────────────────────────────┐
│ 아이템명 [장착 중] / 슬롯 / 가격          │
│ 요약                                      │
│ 효과                                      │
│ [구매] [장착] 또는 [해제]                 │
└───────────────────────────────────────────┘
```

목적:

- 초반 외모/예법/소문 방어 수치를 보조한다.
- 장착 효과는 즉시 `GameState.apply_effects()`로 반영하며, 일부 효과는 행동/맞선/은폐 판정 보정으로도 참조한다.
- 예법서는 예법 훈련 결과를 올리고, 수수한 리본은 맞선 시작 안심/체면을 보정하며, 검은 애도 베일은 공개 애도 은폐 성공률을 올린다.
- 같은 슬롯 아이템을 교체하면 기존 장착 효과를 제거한 뒤 새 효과를 적용한다.
- 장착 중인 아이템은 카드 제목에 표시하고 버튼은 `해제`로 바뀐다.

## 인물

```text
상단 필터:
[전체] [조력자] [후보] [뒷세계] [소문]

┌ NPC 카드 ─────────────────────────────────┐
│ [NPC 초상화]  이름 / 역할                 │
│              공개 요약                    │
│              정보력 충분 시 비공개 단서   │
│              관계 축                      │
│              [대화] [거래] [후보 정보 구입]│
└───────────────────────────────────────────┘
```

목적:

- NPC를 단순 목록이 아니라 관계/정보/상점/라이벌 대응의 허브로 사용한다.
- 역할군 필터로 조력자, 후보, 뒷세계, 소문 관련 NPC를 빠르게 좁힌다.

## 페르소나

```text
┌ 페르소나 카드 ────────────────────────────┐
│ 이름 [현재]                               │
│ 요약                                      │
│ 맞선 보정                                 │
│ [선택] 또는 [잠김]                        │
└───────────────────────────────────────────┘
```

목적:

- 장기 성장 상태와 별개로 현재 사회적 가면을 선택한다.
- 맞선 시작 축에 보정값을 적용한다.

주제
┌ 주제 카드 ────────────────────────────────┐
│ 주제명 / 위험도                           │
│ 설명                                      │

작전
┌ 작전 카드 ────────────────────────────────┐
│ 작전명 / 소요 주 / 기본 성공률            │

목적:

- 정보력과 소문 위험을 후보 발견/라이벌 견제와 연결한다.

## 후보

```text
작위 필터:
[전체 작위] [기사] [남작] [자작] [백작] [후작] [공작]

정렬:
[작위순] [정보순] [난도순] [보안순]

┌ 후보 카드 ────────────────────────────────┐
│ [후보 초상화]  후보명 / 작위 / 정보 품질  │
│               공개 요약                   │
│               정보 품질 30+: 동기/선호/조건 │
│               정보 품질 60+: 보안/특성/압박 │
│               정보 품질 85+: 비공개 단서/약점 │
│               결혼식 최소 준비금 / 현재 자금 │
│               [맞선 시작]                 │
└───────────────────────────────────────────┘
```

데이터 기준:

- 왕족을 제외한 기사/남작/자작/백작/후작/공작 후보는 각 계급 최소 3명씩 둔다.
- 소문 조사, 정보상 거래, 사교 행사, 배우자 처리 이후에는 현재 신분/사교/영향력으로 접근 가능한 후보 중 아직 모르는 인물이 열린다.
- 기사/남작/자작/백작/후작/공작 후보는 실제 초상화를 사용한다.
- 초상화 경로가 비어 있는 미래 후보만 동일한 슬롯에 `초상화 준비중` 상태로 표시한다.
- 작위 필터와 정렬 버튼으로 발견한 후보를 계급, 정보 품질, 난도, 보안 수준 기준으로 재배열한다.

## 맞선

```text
일반 헤더/내비게이션/행동 로그를 숨기고 전용 응접실 배경으로 전환

┌ 혼인 교섭 ─────────────────────────────────┐
│ 대화 2/8 [진행 핍]              남은 대화 07 │
│                       마음이 기울고 있습니다 │
├ 나의 입장 ──── 교섭의 흐름 ───── 혼인 후보 ┤
│ 초상화          호감/신뢰 리본         초상화 │
│ 화법 상태        체면/정략 가치         반응 상태 │
│ 체력/재화        흥미·안심 보조 지표    혼인 난도 │
├ 이전 화제와 대사/상대 반응 ──────────────┤
│ 이번 라운드 실제 변화량                    │
├ 다음 화제를 선택하십시오 ─────────────────┤
│ [화제/효과] [화제/효과] [화제/효과] [화제/효과] │
└────────────────────────────────────────────┘
```

후보 프로필에 `unique_match_choices`가 있으면 기본 선택지보다 먼저 표시한다.
선택지 카드 앞에 `[1]`~`[9]` 키 힌트를 표시하고 해당 숫자 키로 바로 실행할 수 있다. 마우스로 선택한 뒤 화면을 재구성해도 선택지 영역의 기존 스크롤 위치를 유지한다. 마지막 턴 뒤에는 성공/실패 결과 패널을 먼저 표시하고, 확인 버튼을 눌러 결혼식 또는 후보 목록으로 이동한다.

선택지 숙련 규칙:

- 요구 능력치가 없는 기본 화제는 항상 사용할 수 있는 안전 선택지로 남긴다.
- 플레이어 숫자 스탯 요구치는 버튼 잠금이 아니라 권장 숙련치로 처리한다.
- 현재 수치가 기준 이상이면 `충분`, 기준의 40~99%면 `효과↓`, 40% 미만이면 `역효과`로 표시한다.
- `효과↓`에서는 긍정 상승량이 줄거나 사라지고 부작용이 커진다. 정확히 40%인 경계는 긍정 효과 0의 중립 완충점이며, 그 아래 `역효과`에서는 원래의 긍정 효과도 관계 하락으로 반전될 수 있다.
- 플래그·자원·후보 정보처럼 선택 자체가 성립하지 않는 조건만 `hard_requirements`로 잠근다.
- 카드에는 조정된 실제 예상 효과를 표시하고, 툴팁에는 현재/권장 능력치와 부족 결과를 설명한다.
- 같은 화제의 첫 사용은 정상 효과를 내지만, 2회째부터 긍정 효과가 감소하고 흥미가 하락한다. 3회째부터는 안심까지 떨어지며, 4회째 이후에는 신뢰 하락과 강한 역효과 위험이 누적된다.
- 선택지 카드에는 다음 사용이 몇 번째 반복인지와 `효과 감소`/`지루함 누적`/`역효과 위험`을 실제 예상 효과와 함께 표시한다.
- 상대 반응은 첫 반복에서 예의 바른 기시감, 두 번째 반복 이후에는 시선 이탈과 짧아진 대답으로 바뀐다. 반복 이력은 `current_match.choice_history`, 횟수는 `current_match.choice_usage`에 기록해 저장·불러오기 후에도 유지한다.
- 모바일 카드에는 관련 능력 평균과 권장 숙련을 본문에 직접 표시해 호버 툴팁 없이도 `충분/효과↓/역효과`의 원인을 확인할 수 있게 한다.
- 선택 실행 후 `충분`은 기존 대사 단계별 능숙한 문장, `효과↓`는 머뭇거리거나 불완전한 문장, `역효과`는 실언·잘못된 인용·노골적인 질문으로 출력한다. 상대 반응도 수용·경계·냉각으로 달라지고 이전 화제 줄에 당시 숙련 결과를 남긴다.
- 직전 선택의 실제 변화량은 해당 축 숫자 옆 `▲/▼`로 표시하며, 교섭판 중앙에는 호의·관망·경계·실언의 현재 분위기를 문장으로 해석한다.
- 중앙 장력선은 선택 결과의 순효과가 양수면 후보 쪽으로, 음수나 `backfire`면 플레이어 쪽으로 이동한다. 가장 변화가 큰 축의 색을 사용하고 반복 화제일수록 호흡과 잔광을 약하게 만들어 호의·경계·권태를 서로 다른 리듬으로 전달한다.
- 맞선 배경의 광원·휘장·촛불은 같은 순효과와 반복 단계에 반응하며 양측 초상은 성공 시 바깥에서 중앙으로, 경계 시 중앙에서 바깥으로 짧게 이동한다. 실제 패널 폭과 텍스트 배치는 바꾸지 않는다.
- `accessibility/reduce_motion` 프로젝트 설정이 켜지면 장력선·배경·초상의 큰 이동을 정적인 위치 및 약한 잔광으로 축소하고, 컴팩트 화면에서는 진폭과 장력선 높이를 줄인다.
- 플레이어 초상 옆에는 자연스러운 주도/말끝의 흔들림/실언의 여파를, 후보 초상 옆에는 마음이 열림/호의/관망/경계를 표시한다. 기사 핵심 후보 3명은 관망(`neutral`)/호의(`favorable`)/경계(`wary`) 초상 자체가 직전 변화량과 역효과 상태에 맞춰 전환되며, 전용 변형이 없는 후보는 기존 초상 색조·테두리로 동일한 상태를 표현한다. 대사 패널 강조색도 같은 상태를 따른다.
- 맞선 진입 시 이전 일반 화면의 일시 배너를 정리해 전용 교섭 헤더와 게이지를 가리지 않게 한다.

성공 판정:

- 6축 가중 평균
- 페르소나 보정
- 후보 선호 스탯 기반 준비 보너스
- 치명 축이 너무 낮으면 실패
- 실패 시 후보 화면 상단과 행동 로그에 부족 축/점수 차/준비 보너스 사유 표시
- 매 대화 선택 효과에 따라 후보 반응 문장과 관계 상태 문구를 갱신

- 작은 창에서 후보/인물/배우자 초상화 행, 상태 그리드, 필터/저장 버튼이 줄바꿈되도록 보강.
