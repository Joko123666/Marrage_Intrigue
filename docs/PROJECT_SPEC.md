# 프로젝트 구현 명세 v0.1

## 게임 개요

플레이어는 평민 고아 출신의 여성을 조종한다. 주인공은 14세에 시작하며, 슬럼가 생존자의 야성과 굶주림을 가진 상태에서 귀족 사회에 진입한다. 그녀는 귀족의 예법, 교양, 가면술을 배우며 점차 완성된 귀부인처럼 행동하게 되지만, 내면의 야망은 사라지지 않는다.

핵심 목표는 결혼, 사교, 정보전, 제거, 은폐, 정치공작을 통해 신분을 올리고 최종적으로 왕족과의 결혼 또는 권력의 정점에 도달하는 것이다.

## 핵심 루프

```text
자유단계
→ 사냥감 색출
→ 사냥감 선택
→ 자신 연마
→ 맞선 대결
→ 결혼단계
→ 제거/정치처리 단계
→ 은폐단계
→ 자유단계 복귀
```

## 시간 단위

- 최소 단위: 1주
- 모든 장기 행동은 `weeks` 필드를 가진다.
- 행동 실행 후 TimeManager가 주차를 전진시킨다.
- 52주가 지나면 나이가 1 증가한다.
- 30세부터 결혼 시장 페널티를 주고, 35세를 강한 종료 후보로 본다.

## 주인공 성장 핵심

대사 단계와 페르소나를 분리한다.

- 대사 단계: 장기 성장 상태. 예: 골목의 짐승 → 궁정의 포식자.
- 페르소나: 현재 사회에 보여주는 공개 이미지. 예: 순진한 보호대상, 비탄의 미망인, 품격 있는 궁정 귀부인.

## 초기 수직 절편 범위

초기 버전은 다음만 완성한다.

```text
14세 시작
→ 자유행동으로 외모/예법/정보력 상승
→ 기사 후보 색출
→ 우연을 가장한 만남
→ 맞선 레이더 승부
→ 결혼
→ 배우자 대시보드 확인
→ 제거 또는 정치처리 준비
→ 은폐
→ 남작 후보 접근권 획득
```

## 구현 원칙

- 데이터 주도 구조를 우선한다.
- 숫자 변화는 로그에 남긴다.
- 플레이어가 실패 원인을 이해할 수 있게 한다.
- 후반 작위 확장은 핵심 루프가 재미있다는 검증 뒤 진행한다.
