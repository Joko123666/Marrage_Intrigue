# 스테이터스 영향 시스템

## 목표

스테이터스는 행동을 잠금 해제하는 열쇠에 그치지 않고 다음 세 층위에 지속적으로 영향을 준다.

1. **접근 가능성**: `requirements`는 행동 자체가 가능한지를 판정한다.
2. **수행 품질**: `stat_influence.stats`의 가중 평균이 성공률과 결과 크기를 결정한다.
3. **현재 컨디션**: 피로와 스트레스가 높으면 숙련된 인물도 제 기량을 내지 못한다.

구매, 장착, 화면 이동처럼 숙련과 무관한 기능에는 `stat_influence`를 두지 않는다.

## 데이터 형식

```json
"stat_influence": {
  "stats": {
    "information": 0.5,
    "mask": 0.3,
    "social": 0.2
  },
  "reference_stat": 40,
  "chance_per_point": 0.5,
  "fixed_effects": ["cash"]
}
```

- `stats`: 행동 수행에 쓰는 능력치와 가중치. 합계는 보통 1.0으로 작성한다.
- `reference_stat`: 데이터에 기록된 기본 효과와 기본 성공률이 그대로 나오는 기준 숙련도.
- `chance_per_point`: 기준 숙련도와의 차이 1점이 성공률 몇 %p가 되는지 지정한다.
- `fixed_effects`: 능력과 무관하게 항상 동일해야 하는 비용이나 결과.
- `ignore_condition`: 휴식처럼 피로·스트레스 페널티를 받지 않는 행동에 사용한다.
- `positive_max_multiplier`: 성장 보상의 상한을 별도로 낮춰야 하는 훈련 등에 사용한다.
- 작위 단계인 `status`는 내부 0~6 값을 판정 시 0~100으로 정규화한다.

## 공통 계산

`숙련 = Σ(현재 스탯 × 가중치) / Σ가중치`

`현재 성공률 = 기본 성공률 + (숙련 - 기준 숙련) × 성공률 계수 + 컨디션 + 상황 보정`

- 피로와 스트레스는 각각 40까지 페널티가 없다.
- 40을 넘긴 피로는 1점당 `-0.12%p`, 스트레스는 `-0.10%p`다.
- 성공률은 기본적으로 5~95% 범위로 제한한다.
- 높은 숙련은 유리한 효과를 최대 1.5배로 키우고 불리한 효과를 최대 0.6배로 줄인다.
- 낮은 숙련은 유리한 효과를 최소 0.75배로 줄이고 불리한 효과를 최대 1.25배로 키운다.
- 위험 축은 감소가 유리한 결과로 간주한다.

## 시스템별 능력 역할

| 시스템 | 주요 능력 | 적용 결과 |
|---|---|---|
| 자유행동 | 행동별 훈련 보조 능력, 정보, 사교, 가면 | 성장량, 수입, 피로와 위험 |
| 인물 상호작용 | 사교, 기품, 가면, 정보 | 호감·의심·정보 획득량 |
| 소문 작전 | 정보, 사교, 가면, 영향력 | 성공률, 정보 획득, 실패 흔적 |
| 맞선 | 선택지 태그의 `uses_stats` | 레이더 상승량과 선택지 부작용 |
| 결혼 생활 | 사교, 기품, 예법, 가면, 정보 | 애정, 공개 금슬, 경계와 피로 |
| 제거·정치처리 | 방식별 정보, 가면, 통제, 사교, 영향력 | 성공률과 사건 초기 위험 |
| 은폐 | 행동별 가면, 정보, 사교, 기품, 영향력 | 성공률, 위험 감소량, 실패 후폭풍 |

## 밸런싱 원칙

- 요구조건은 “시도할 자격”, 기준 숙련도는 “안정적으로 수행할 수준”으로 분리한다.
- 단일 능력치가 모든 상황의 정답이 되지 않도록 행동마다 2~4개 능력치를 조합한다.
- 상위 작위 행동일수록 `reference_stat`을 높이고, 단순히 기본 성공률만 낮추지는 않는다.
- 현금처럼 명시된 지불 비용은 `fixed_effects`로 보존한다.
- UI에는 현재 성공률, 사용 능력과 가중치, 컨디션·상황 보정, 실제 예상 효과를 실행 전에 표시한다.
